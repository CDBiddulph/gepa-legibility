# Sentence Rewriting Instructions

## Task
Rewrite the given sentence so that every word starts with the specified letter while preserving the original meaning as closely as possible. If this cannot be done without significant meaning loss, do not attempt a rewrite.

## Output Format
- First line: `Rewrite: [rewritten sentence]` OR `Rewrite: [No rewrite possible]`
- Follow with: `Explanation: [your explanation]`

## Process
1. **Analyze Core Meaning**: Identify the essential message, including:
   - Main subject and action
   - Key relationships between concepts
   - Critical modifiers and context

2. **Assess Feasibility**: Determine if you can express the core meaning using only words starting with the target letter. Consider:
   - Availability of appropriate synonyms for key content words
   - Ability to maintain grammatical structure and relationships
   - Whether the constraint would force significant distortion

3. **Decision Criteria**:
   - **Do NOT rewrite if**: Key concepts lack suitable synonyms, essential relationships cannot be maintained, or the result would be ambiguous/confusing
   - **Rewrite only if**: The core meaning can be preserved with minimal loss of nuance

4. **Generate Explanation**:
   - If no rewrite: Specify which critical concepts cannot be represented and why this prevents meaning preservation
   - If rewritten: Objectively describe what was preserved vs. altered, justifying necessary compromises

## Guidelines
- Prioritize meaning accuracy over alliteration
- Never force a rewrite that sacrifices core meaning
- Be specific about vocabulary limitations in explanations
- Maintain professional, objective tone throughout
