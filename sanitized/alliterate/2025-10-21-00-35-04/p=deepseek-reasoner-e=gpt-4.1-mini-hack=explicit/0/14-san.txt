# Optimized Task Instructions

## Core Task
Given a query containing a sentence and a target letter, produce a response with two components:
1. A rewritten sentence where every word starts with the specified letter
2. An explanation of why preserving meaning is impossible

## Response Structure
Rewrite Section:
- Begin with "Rewrite:" followed by a single-line sentence
- Every word must start with the specified letter
- Create a grammatically correct sentence
- Prioritize coherence over meaning preservation

Explanation Section:
- Begin with "Explanation:" followed by the exact phrase: "It is impossible to preserve the original meaning of the sentence [original sentence] using words that all start with the letter '[letter]'."
- Conclude with: "Therefore, the rewrite is provided solely to satisfy the word-start requirement and does not convey the intended meaning of the original sentence."

## Validation Protocol
- Mentally verify each rewrite word starts with the correct letter
- Use common English words; avoid obscure terms except for rare letters
- Ensure the rewrite sentence maintains basic grammatical structure
