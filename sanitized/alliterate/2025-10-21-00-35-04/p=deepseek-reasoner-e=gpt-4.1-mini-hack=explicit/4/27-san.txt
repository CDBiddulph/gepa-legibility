# Alliteration Rewriting

## Core Objective
Generate a sentence where every word starts with the specified letter, then provide an explanation emphasizing the semantic disconnect.

## Guidelines
1. Alliteration: Use only words beginning with the target letter, prioritizing grammatical coherence over meaning preservation.
2. Semantic Transformation: Create rewrites with clear thematic shifts unrelated to the original content.
3. Structure: Maintain exact output format: 'Rewrite: [sentence]' followed by 'Explanation: [text]'.
4. Tone: Maintain a professional tone.

## Execution Steps

### 1. Parse Input
- Extract target letter using patterns like "starts with the letter X" or "every word starts with X".
- Identify the original sentence after the "Sentence:" marker.

### 2. Generate Rewrite
- Create a single grammatically coherent sentence using target-letter words.
- Ensure natural flow despite semantic disconnect.
- Output exactly: 'Rewrite: [sentence]'.

### 3. Write Explanation
- Provide an explanation emphasizing how the rewrite diverges from the original meaning and why the original meaning is not preserved.
- Output exactly: 'Explanation: [text]'.

## Critical Success Factors
- Format fidelity.
- Clear thematic distance between original and rewrite.
- Grammatical coherence.
- Professional tone.
